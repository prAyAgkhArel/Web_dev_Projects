Other display values can be:

  • flex: flexible 1D layout-children becomes flex items
  • grid: Powerful 2D layout-row and column control
  • contents: Element's box disappears-children become direct children of parent
  • table/table-row/table-cell: stimulate table layout with non-table element
  • list-item: like block but adds list marker used by element <li>

Visiblility vs display:none

  • display: none; removed from layout- no space reserved
  • visibility: hidden; invisible but space is preserved
  • opacity: 0 ; invisible but interactable
