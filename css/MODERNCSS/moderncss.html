Modern CSS

CSS Functions: clamp(), min(), max():

clamp(min, preferred, max)

font-size: clamp(1rem, calc(2vw + 0.5rem), 2rem);
width: clamp(200px, 50%, 800px)

min()

width: min(500px, 90%)
90% on small screens, 500px on large
padding: min(5vw, 3rem);

max()

font-size: max(1rem, 2vw); i.e. At least 1 rem, grows with viewport

calc()

width: calc(100% - 2rem);
margin-left: calc(50%-300px);

Container Queries:

Mark the container

.card-container{
container-type: inline-size;
container-name: card;
}

Query It

@container(min-width:400px){
.card{ display:grid; grid-template-columns: 1fr, 1fr; }
}

  • clip-path: circle(50%);
  • clip-path: ellipse(50% 40% at 50% 50%);
  • clip-path: polygon(0 0, 100% 0, 100% 100%, 0 100%);
  • clip-path: inset(10px 20px round 8px);
Animate it!

.shape{ clip-path: polygon(0 0, 100% 0, 100% 100%, 0 100%);
transition: clip-path 0.4s ease; }

.shape:hover{ clip-path: polygon(0 0, 100% 0, 80% 100%, 20% 100%); }
