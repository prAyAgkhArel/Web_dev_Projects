Pseudo Classes and Elements

Pseudo-Classes -State and Position:

:hover

Mouse over element

:focus

Element has keyboard focus

:focus-visible

Focus visible(not mouse click)

:focus-within

Any child is focused

:active

Being Clicked

:visited

Visited link

:checked

Checked Input

:disabled

Disabled form element

:enabled

Enabled form element

:placeholder-shown

Input with visible placeholder

:required

Required input

:optional

Non-required input

:valid

Input with valid value

:invalid

Input with invalid value

:in-range

Number input within min/max

:out-of-range

Number input outside min/max

:read-only

Non-editable input

:read-write

Editable input

:empty

Element with no children

:root

Root element(html)

:first-child

First child of parent

:last-child

Last child of parent

:only-child

Only child of parent

:nth-child(n)

nth child(e.g. 2n+1=odd)

:last-of-type

last of element type

:nth-of-type(n)

nth of its type

:not(selector)

Does not match selector

:is(a,b,c)

matches any -lower specificity

:where(a,b)

Like :is() but zero specificity

:has(selector)

parent with matching child

:target

ID matches URL hash

:lang(code)

Language attribute match

Pseudo Elements:

::before

Generated content BEFORE element's content

::after

Generated Content AFTER element's content

::first-line

First line of text block

::first-letter

First letter (drop caps)

::selection

User's selected text

::placeholder

Placeholder text in inputs

::marker

List item bullet/number

::file-selector-button

<input type="file"> button

::backdrop

Behind a <dialog> or fullscreen element

::spelling-error

Misspelled text(chrome)

::grammar-error

Grammatical errors
