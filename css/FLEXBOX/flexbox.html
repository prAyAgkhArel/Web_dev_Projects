OTHER FLEX ITEMS PROPERTIES:

.flex-item{
order: 0; Reorder items without changing html
flex-grow: 0; How much to grow. 0=donot grow 1= grow to fill
flex-shrink: 1; How much to shrink. 0=donot shrink
flex-basis: auto; Initial size before growing or shrinking
flex: 1; shorthand grow=1, shrink=1, basis=0
flex: 0 0 200px; fixed size-won't grow or shrink
align-self: auto; Override parent's align-items for this item auto/flex-start/flex-end/stretch/baseline
}
