Positioning

position values

The position property takes an element out of (or keeps it in) the normal document flow.

class 'first' h3 , its position is static.

class 'second' h3 , its position is relative.

class 'third' h3 , its position is absolute. positioned relative to viewport.

class 'fourth' h3 , its position is sticky.

class 'fifth' h3 , its position is fixed. Scroll and see !! e.g yt navbar
